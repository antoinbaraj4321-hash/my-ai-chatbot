# My AI Chatbot

A simple AI chatbot built using Python, Flask, Ollama, and SQLite.

## Features

- AI-powered chat using Ollama
- Local AI model integration (Llama 3.2 1B)
- Chat history storage using SQLite
- View previous conversations
- Clear chat history

## Technologies Used

- Python
- Flask
- Ollama
- SQLite
- HTML
- CSS
- JavaScript

## Installation

1. Clone the repository:
   `git clone https://github.com/antoinbaraj4321-hash/my-ai-chatbot.git`

2. Install dependencies:
   `pip install flask ollama`

3. Download model:
   `ollama pull llama3.2:1b`

4. Run:
   `python app.py`

5. Open:
   `http://127.0.0.1:5000`
